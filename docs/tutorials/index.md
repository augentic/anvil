# Tutorials

Hands-on walkthroughs that take you from zero to a working Specify change. Each tutorial builds on the previous one.

Before you start, complete [Prerequisites](../orientation/prerequisites.md) (Cursor, Augentic plugins, `specify` CLI, and adapter tooling).

| Tutorial | Time | You will… |
| -------- | ---- | --------- |
| [Quick start](quick-start.md) | ~30 min | Run a one-slice Omnia change from intent through finalize |
| [Your first multi-slice change](first-change.md) | ~45 min | Plan and execute three dependent slices from documentation |
| [Cross-repo changes](cross-repo-change.md) | ~60 min | Coordinate a change across workspace project slots |
| [Legacy migration at scale](legacy-migration-at-scale.md) | ~15 min read | Learn how legacy code enters the workflow |

After the quick start, skim [Core concepts](../explanation/concepts.md) for vocabulary, then bookmark the [Quick reference card](../reference/quick-reference.md) for daily lookup.
