# Specify Operator Guide

Specify is a plugin system that orchestrates spec-driven software development inside [Cursor](https://cursor.com). Each change flows through a defined lifecycle -- **define**, **build**, **merge** -- with structured artifacts that capture intent, requirements, design, and implementation sequencing. All artifacts are version-controlled alongside your code.

This guide is organised in two halves:

- **[Tutorials](tutorials/index.md)** walk you through progressively complex scenarios, from a single change to multi-repo platform initiatives.
- **[Reference](reference/index.md)** provides the complete lookup table for every skill, CLI command, artifact format, and configuration file.

Start with the [Orientation](orientation/index.md) to build the mental model, then work through the tutorials in order. Return to the reference when you need precise detail on a specific topic.
