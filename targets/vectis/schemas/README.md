# Vectis shared schemas

JSON Schemas (draft 2020-12) for the artifacts the Vectis target consumes and emits. Relocated from `adapters/vectis/` in Specify 2.0; the published `$id` URLs now resolve under `targets/vectis/schemas/<name>.schema.json` (see [docs/migration/2.0.md](../../../docs/migration/2.0.md#vectis-schema-relocation)).

- [`composition.schema.json`](composition.schema.json) — JSON Schema for `composition.yaml`. Regenerated by [`targets/vectis/briefs/build.md`](../briefs/build.md); validated by `specify tool run vectis -- validate composition`.
- [`tokens.schema.json`](tokens.schema.json) — JSON Schema for the operator-curated `tokens.yaml` build input.
- [`assets.schema.json`](assets.schema.json) — JSON Schema for the operator-curated `assets.yaml` build input.
