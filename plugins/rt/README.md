# RT Migration

Fixture capture, repository cloning, and regression testing for migration workflows. Source code analysis has moved to `/spec:extract` in the spec plugin.

## Skills

| Skill | Description |
|-------|-------------|
| [git-cloner](skills/git-cloner/SKILL.md) | Clone a source repository as a detached tree for analysis |
| [replay-writer](skills/replay-writer/SKILL.md) | Add regression tests from captured real-world fixtures |
| [wiretapper](skills/wiretapper/SKILL.md) | Capture fixture data from legacy services |
