## Findings to action

### F1 — `one-driving-mode-per-project` invariant not enforced  (severity: high — release blocker for full gate)

- **Symptom:** With an approved workspace plan (`oauth-login`) routing a slice to `shop-backend`, `specify plan create local-change` run from `shop-backend/`'s own root **succeeded (exit 0)** and wrote a competing `shop-backend/plan.yaml`. Expected: structured refusal citing the one-driving-mode-per-project invariant.
- **Evidence:** [`dual-driving-refused-2026-06-06.md`](dual-driving-refused-2026-06-06.md); preserved temp root `/private/tmp/specify-acceptance-dual.6kYDWl`.
- **Root-cause observation:** the registered project's `.specify/project.yaml` has no back-reference to the owning workspace / active plan, so `plan create` has no signal to detect dual-driving. Guard appears unimplemented (or depends on a sync-written marker that is not written).
- **Owner repo:** `augentic/specify-cli` (`crates/workflow` plan create + workspace sync).
- **Action:** [ ] File issue in `augentic/specify-cli`; decide enforcement mechanism (sync-written project marker vs. registry lookup at `plan create`); add a regression test mirroring this scenario.

### F2 — `tasks.md` format: synthesis playbook contradicts the validator  (severity: medium — blocks refine if followed literally)

- **Symptom:** `references/synthesis/substeps.md` §4 and `plugins/spec/references/synthesis/README.md` document tasks as `- [ ] <description>`. The `tasks.use-checkbox-format` validator and `docs/reference/artifact-format.md` require the numbered `- [ ] X.Y` form. Authoring per the playbook produced a **blocking** `tasks.use-checkbox-format` finding at `specify slice validate`; re-authoring as `- [ ] 1.1 …` cleared it.
- **Evidence:** [`pure-intent-2026-06-06.md`](pure-intent-2026-06-06.md) (Verdict notes).
- **Owner repo:** `augentic/specify` (docs).
- **Action:** [ ] Reconcile the two doc surfaces with the validator — update `references/synthesis/substeps.md` §4 and `synthesis/README.md` to show `- [ ] X.Y …` (or relax the validator), so refine authoring matches what passes.
