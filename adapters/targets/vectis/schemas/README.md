# Vectis runtime schemas

JSON Schemas (draft 2020-12) for the artifacts the Vectis target consumes and emits. Schemas are owned by the WASI tool that runs them (RFC-31 D1); this directory holds no schema bodies. Canonical `$id` URLs:

- [`composition.schema.json`](https://schemas.specify.dev/vectis/composition.schema.json) — JSON Schema for `composition.yaml`. Regenerated by the Vectis target's [`build` brief](../briefs/build.md); validated by `specrun tool run vectis -- validate composition`.
- [`tokens.schema.json`](https://schemas.specify.dev/vectis/tokens.schema.json) — JSON Schema for the operator-curated `tokens.yaml` build input.
- [`assets.schema.json`](https://schemas.specify.dev/vectis/assets.schema.json) — JSON Schema for the operator-curated `assets.yaml` build input.

## Retrieving schema bodies

```bash
specrun tool schema vectis composition
specrun tool schema vectis tokens
specrun tool schema vectis assets
```

Each command prints the tool-embedded schema as pretty-printed JSON to stdout.
