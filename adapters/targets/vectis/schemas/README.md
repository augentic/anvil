# Vectis shared schemas

JSON Schemas (draft 2020-12) for the artifacts the Vectis target consumes and emits. The published `$id` URLs resolve under `adapters/targets/vectis/schemas/<name>.schema.json`.

- [`composition.schema.json`](composition.schema.json) — JSON Schema for `composition.yaml`. Regenerated by [`adapters/targets/vectis/briefs/build.md`](../briefs/build.md); validated by `specify tool run vectis -- validate composition`.
- [`tokens.schema.json`](tokens.schema.json) — JSON Schema for the operator-curated `tokens.yaml` build input.
- [`assets.schema.json`](assets.schema.json) — JSON Schema for the operator-curated `assets.yaml` build input.
