# Structured run reports

Live profile bundles are written here as `<scenario>-<profile>-<timestamp>/`. Each bundle contains a top-level `report.json` plus one evidence directory per trial.

Commit release-gate reports that informed a release decision. Ad-hoc development bundles may remain local and should be removed before unrelated commits. Historical Markdown records under `evals/runs/` are preserved as legacy audit evidence and are not rewritten into this format.
